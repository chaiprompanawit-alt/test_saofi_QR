# ระบบแจ้งซ่อมไฟฟ้าสาธารณะ — เทศบาลตำบลป่าสัก (MVP)

สแกน QR ที่เสา → ระบบรู้ทันทีว่าเป็นเสาต้นไหน (ไม่ต้องกรอกเลขเสาเอง) → เก็บพิกัด Lat/Long →
ช่างไฟดูงานทั้งหมดบนแดชบอร์ด + แผนที่ + อัปเดตสถานะแบบ incident

## องค์ประกอบ
| ไฟล์ | หน้าที่ |
|---|---|
| `apps_script/Code.gs` | เซิร์ฟเวอร์ (รับแจ้ง / อ่าน-อัปเดตงาน) |
| `apps_script/report.html` | หน้าชาวบ้านแจ้งซ่อม (เปิดจาก QR) |
| `apps_script/admin.html` | แดชบอร์ดช่างไฟ + แผนที่ (Leaflet ฟรี ไม่ต้องมี API key) |
| `apps_script/poles_template.csv` | เทมเพลตข้อมูลเสา + พิกัด |
| `docs/qr_generator.html` | สร้าง QR รายเสาแบบ pre-filled แล้วสั่งพิมพ์ |

## ขั้นตอนติดตั้ง (ครั้งเดียว ~30 นาที)

### 1) เตรียม Google Sheet
1. สร้าง Google Sheet ใหม่ (แนะนำใช้ **บัญชี Google ของ อบต.** ไม่ใช่ส่วนตัว)
2. สร้างชีตชื่อ **`Poles`** — วางข้อมูลจาก `poles_template.csv` (คอลัมน์: `pole_id, zone, address, lat, lng, note`)
   - พิกัด lat/lng: ยืนที่เสา เปิด Google Maps กดค้างจุดที่ยืน → คัดลอกเลข 2 ตัว
3. สร้างชีตชื่อ **`Reports`** — ปล่อยว่าง ระบบจะเติมหัวตารางเอง

### 2) ติดตั้ง Apps Script
1. ใน Sheet: เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. วางเนื้อหา `Code.gs` ลงไฟล์ `Code.gs`
3. กด **+** เพิ่มไฟล์ HTML ชื่อ `report` และ `admin` → วางเนื้อหาจาก `report.html` / `admin.html`
   (ใส่ชื่อ **report** และ **admin** เท่านั้น ไม่ต้องมี .html)
4. ในไฟล์ `Code.gs` แก้บรรทัด `ADMIN_TOKEN = 'CHANGE_ME_2568'` เป็นรหัสลับของเจ้าหน้าที่

### 3) Deploy เป็น Web App
1. กด **Deploy → New deployment → เลือกชนิด Web app**
2. ตั้งค่า: **Execute as = Me**, **Who has access = Anyone**
3. กด Deploy → อนุญาตสิทธิ์ → คัดลอก **Web app URL** (ลงท้าย `/exec`)

### 4) สร้าง QR รายเสา
1. เปิด `docs/qr_generator.html` ในเบราว์เซอร์
2. วาง Web App URL + ใส่รายการเลขเสา → กดสร้าง → พิมพ์ติดที่เสา

### 5) ใช้งาน
- **ชาวบ้าน:** สแกน QR เสา → หน้าจอโชว์เลขเสาให้เลย → กรอกชื่อ/เบอร์/อาการ → ส่ง
- **ช่างไฟ:** เปิด `WebAppURL?page=admin` → ใส่รหัส → เห็นงานทั้งหมด + หมุดบนแผนที่ + กดนำทาง Google Maps + เปลี่ยนสถานะ/มอบหมาย/บันทึก

## หมายเหตุ
- **ต้นทุน:** ~0 บาท (รันบน Google) — ดูรายละเอียดในเอกสารแผนธุรกิจ (private)
- ลิงก์นำทางเปิด Google Maps ได้เลย แต่ตัวแผนที่ในแดชบอร์ดใช้ OpenStreetMap จึงไม่ต้องเสียค่า API key
- ข้อมูลผู้แจ้งเป็นข้อมูลส่วนบุคคล (PII) — อย่า export ขึ้น repo สาธารณะ
